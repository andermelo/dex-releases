# DEX Hub downloads

Official signed and notarized DEX Hub builds for macOS.

DEX Hub connects your Mac to the DEX iPad canvas. Download the latest DMG from Releases, open it, and drag DEX Hub to Applications. macOS 14 or later is required.

Claude Code or Codex must be installed and authenticated separately for AI features. App development previews also require Xcode and an iOS Simulator.
